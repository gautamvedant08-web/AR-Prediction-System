# AR Prediction System – Machine Learning

## Project Overview
The AR (Accounts Receivable) Prediction System is a Machine Learning project designed to analyze invoice and payment data to help businesses understand customer payment behavior, predict payment delays, identify payment risks, and forecast future cash collections.

## Project Objectives
- Predict invoice payment delays.
- Estimate expected payment/settlement time.
- Identify customers with a higher risk of late payment.
- Forecast cash collections for the next 30, 60, and 90 days.

## Dataset
**Dataset:** Global B2B Invoice & Payments

- Total Records: 2,000,000
- Total Features: 31
- Data Type: Structured financial and invoice data
